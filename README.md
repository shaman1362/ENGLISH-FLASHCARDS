# Sharmin’s English Flashcards

Five four-option English practice cards with Persian answer explanations, based on the supplied HTML.

Topics: impact, supplier, let someone know, compound adjectives, and project delays.

Choose an answer to reveal correct/incorrect colors and the Persian explanation. Navigate using previous/next.

Open `index.html` locally or use GitHub Pages enabled for the main branch root.

This version provides manual review, not an automated spaced repetition scheduler.
